01 · Why

清洗的难点不是“找坏数据”，
而是别把未知当正常。

时间容易算错

LeRobot V3 的 episode 时间与共享视频文件时间不是一回事。区间猜测会让跨 episode 映射悄悄漂移。

局部坏 ≠ 整条坏

短暂 tracking 丢失、action 卡住或某只手失效，应该 mask 窗口或保留有效片段，而不是删除整条 episode。

缺证据不能算通过

没有标定绑定、EEF link、mask provider 或 train reference 时，结果必须是 N/A，并显式降低 coverage。

07 · What We Have Now

现在得到的不是一个“神奇分数”，
而是一个可复查的决策面。

已能稳定运行

Raw → prefilter → eligible → 官方 LeRobotDataset V3 → deep clean → online FINAL_V2 chunk → UI evidence。

DONE

下一份最有价值的依赖

本地 SAM3 权重或受控 API provider，才能把 Robot C2 从 N/A 提升为真实 mask/projection/IoU 证据。

DEPENDENCY

再往后才考虑

全量 train-only 发布、训练期 normalization 与采样策略；仍不把 Motive/梯度归因放进预清洗。
